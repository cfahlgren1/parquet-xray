# Contributing

Thanks for helping. Bug reports with a link to the Parquet file that misbehaves are the most useful thing you can send.

## Setup

You need Node 22 or newer.

```sh
npm install
npm run dev          # http://localhost:5173
```

Open `http://localhost:5173/?url=sensors.parquet` to load the bundled example, or paste any Hub file URL.

## Before opening a pull request

```sh
npm run verify       # lint, type-check, unit tests, build
npm run test:e2e     # browser tests (first run: npx playwright install chromium)
```

`npm run format` fixes formatting and autofixable lint errors.

## Where things live

| Path                          | What it does                                                                                                                                                                       |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/lib/parquet/`            | Everything about the file, with no UI: fetching the tail, building the byte layout (`model.ts`), schema lines, statistics and read-efficiency checks. Start here for parsing bugs. |
| `src/lib/inspector.svelte.ts` | The loaded file plus the user's selection (row group, column, popover). Components read it from context.                                                                           |
| `src/lib/popover.ts`          | What the popover says about each kind of byte range.                                                                                                                               |
| `src/lib/paint.ts`            | Canvas helpers for the file strip: per-pixel dominant color and hit testing.                                                                                                       |
| `src/lib/share.ts`            | The `?url=&rg=&col=` link format and syncing it to the Hub page around the Space.                                                                                                  |
| `src/components/`             | One Svelte 5 component per section of the page.                                                                                                                                    |
| `tests/`                      | Vitest tests that load real Parquet files from `public/` and `tests/fixtures/`.                                                                                                    |
| `e2e/`                        | Playwright tests against the production build, on desktop and mobile viewports.                                                                                                    |

## Conventions

- Svelte 5 runes (`$state`, `$derived`, `$props`) only.
- Parquet logic goes in `src/lib/parquet/` as plain functions with a test on a real file, not in components.
- Styles are scoped to their component. Shared colors, radii and fonts are CSS variables in `src/app.css`.
- Test fixtures are generated by `uv run scripts/make-fixtures.py`, so they can be rebuilt instead of hand-edited.

## Deploying

Merges to `main` deploy to the [Space](https://huggingface.co/spaces/cfahlgren1/parquet-xray) through `.github/workflows/deploy.yml`, which needs an `HF_TOKEN` secret with write access. `scripts/deploy-space.sh` does the same by hand. It uploads the committed source with `space.yml` as the README's front matter, and the Space runs `npm run build` itself.
